# 验真 · Edge 扩展（阶段 2.1）

选中一段文字 → 按 `Ctrl+Shift+X` → 浮动卡片告诉你**能不能信**，以及**凭什么**。

## 装到 Edge 上（不用上架商店，3 分钟）

1. 打开 Edge，地址栏输入 **`edge://extensions`** 回车
2. **打开左下角的「开发人员模式」开关**
3. 点上方出现的 **「加载解压缩的扩展」**
4. 选中这个文件夹：`C:\Users\jxj\Desktop\AgentWork\yanzhen\extension`
5. 装好后会自动弹出设置页（没弹的话：点扩展图标 → 齿轮/右键 → **扩展选项**）
6. 填两个 key，点「保存」，再点「测试连接」确认模型通
   - DeepSeek：https://platform.deepseek.com/
   - Tavily：https://app.tavily.com （每月 1000 次免费，不用信用卡）
7. 随便打开一个网页，**用鼠标选中一段话**，按 **`Ctrl+Shift+X`**

## 三种触发方式（哪个顺手用哪个）

| 方式 | 操作 |
|---|---|
| **快捷键** | 选中文字 → `Ctrl+Shift+X` |
| **右键菜单** | 选中文字 → 右键 → 「用『验真』核查选中的文字」 |
| **点图标** | 选中文字 → 点工具栏上的验真图标 |

> 快捷键冲突了？去 `edge://extensions/shortcuts` 改成别的。
> Chrome 也能装同一份代码（`chrome://extensions`，步骤一样）。

## 界面说明

```
┌──────────────────────────────────┐
│ 验真  划词事实核查            ×  │  ← 按住这里可以拖动卡片
├──────────────────────────────────┤
│ 🔴 与事实不符（2 条断言中 1 条…）│
│                                  │
│ 1. 隔夜水、千滚水会致癌          │
│    🔴 与事实不符  置信度 85%     │
│    理由：A 级中国农大及 B 级…    │
│    引用来源等级：A×1 B×2         │
│    · [A] 中国农业大学 …          │
│    · [B] 隔夜水、千滚水…-新华网  │
└──────────────────────────────────┘
```

- **等级标签** `[A]`/`[B]`/`[C]`/`[D]`：A=官方一手，B=权威媒体，C=专业机构，D=自媒体百科。
  判定「可信 / 与事实不符」至少要有一条 A 或 B 级来源撑着。
- **证据不足**时会明说查不到，不会猜。
- 按 `Esc` 或点 `×` 关掉卡片。
- **同一个页面再查同一段文字，直接复用上次结论，不花钱。**

## 这一版的已知限制

1. **冷启动可能给出不同答案**：同一段文字第一次查（换机器、或缓存过期后）结果可能与上次不同。
   原因是检索回来的网页每次不一样。缓存期内重复查是一致的。
   （详见项目根目录 `README.md` 的「已知限制」）
2. **争议话题倾向给确定答案**：阿斯巴甜、NMN 这类尚无定论的，它可能直接说可信/不符，
   而不是「证据不足」。这是当前评测里最弱的一环。
3. **只能在浏览器里划词**：管不到微信、Word、PDF 阅读器。要覆盖全系统得另做。
4. `文件://` 页面、Edge 内置页面（`edge://`、扩展商店）里用不了。
5. 还没做图标，工具栏上显示的是默认拼图图标。

## 更新了代码之后怎么生效

改完 `extension/` 里的文件，**必须回 `edge://extensions` 点一下这张卡片上的「重新加载」**，
改动才会生效（否则跑的还是旧代码）。

## 每次核查做了什么（0.2.0 起）

- **双语检索**：同一条断言，中文搜一遍、英文搜一遍（科普/健康类内容英文资料质量更好）
- **新闻模式**：涉及"今年/最近/昨天"的断言，额外搜一次最近 30 天的新闻，结果带发布时间
- **来源分级**：A 官方一手 / B 权威媒体 / C 专业机构 / D 自媒体百科 / 未分级
  （名单含中文与**国际**来源：BBC、路透、美联社、各国政府、WHO、Snopes 等）
- **「未分级」不再等于弱证据**：2 条以上相互独立的未分级来源结论一致时，可以据此判定
- **证据按等级取舍**：每条断言只留最强的 6 条，弱来源被挤掉（控成本）

## 文件说明

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展配置：快捷键、权限、注入规则 |
| `core.js` | **内核**（由 Python 版翻译而来）：拆断言 → 双语检索 → 来源分级 → 判定 → 校验引用 |
| `background.js` | 后台：接快捷键/右键，跑内核，管缓存 |
| `content.js` | 页面脚本：取选中文字、渲染浮动卡片 |
| `options.html` / `options.js` | 设置页：填 key、调成本参数 |
