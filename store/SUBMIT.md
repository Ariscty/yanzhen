> 按顺序做。**先上 Edge（免费、快），跑通了再上 Chrome（要 $5）。**

## 第 0 步：先自己装上跑一遍（10 分钟）

**没跑通就别提交。** 本地加载就失败的包，审核必然不过。

先跑两个自动检查（都不花钱）：

```bash
python store/test_core.py       # 内核逻辑 + JS 语法，应显示「通过 27 / 失败 0」
python store/pack.py            # 自检通过才出包
```

然后手动装一遍：

1. Edge 地址栏输 `edge://extensions`
2. 打开左下角**「开发人员模式」**
3. 点**「加载解压缩的扩展」**，选 `...\yanzhen\extension` 文件夹
4. 装好后**图标应该显示成放大镜 + 绿对勾**（如果还是默认拼图，说明 manifest 没生效，回来告诉我）
5. 打开设置页，填 DeepSeek + Tavily 两个 key，点**「测试连接」**
6. 随便开个网页，选中一段话，按 `Ctrl+Shift+X`
7. **看图标准确显示**，工具栏图标正常

## 第 1 步：把仓库搞成公开的

隐私政策 URL 必须是任何人都能打开的页面。

1. **先跑密钥自检**（本机没 git 命令也能跑，直接读 `.git` 内部）：`python store/check_secrets.py`
   —— 它拿你 `.env` 里的真实密钥逐字节比对整个 git 历史，命中就是真泄露，没有误报。
   当前结果：**✓ 干净**
2. GitHub 仓库 → Settings → 最下面 Danger Zone → **Change visibility → Public**
3. 确认这个链接能打开（无痕窗口里试一下）：
   `https://github.com/Ariscty/yanzhen/blob/main/PRIVACY.md`

> ⚠️ 公开前**务必确认 `.env` 没被提交进去**（里面有你的 API key）。
> 直接跑 `python store/check_secrets.py`，它会用真实密钥比对整个 git 历史。
> （也可以 `git log --all -- .env` 复核，但本机没装 git 命令。）

## 第 2 步：上架 Edge（免费，建议先做这个）

1. 打开 https://partner.microsoft.com/dashboard/microsoftedge/public/login
2. 用 **Microsoft 账号**登录（**可以直接用 GitHub 账号登录**，微软会帮你建一个 MSA）
3. 注册 Microsoft Edge 计划 —— **不收费**
   - 账户类型选 **个人**（公司账户要走资质验证，几天到几周，你现在不需要）
   - 填发布者显示名称（比如 `Ariscty`，全球唯一，被占了就换一个）
   - 填联系人邮箱
   - 同意开发者协议 → 完成
4. **等账号验证通过**（个人账户通常较快，验证发布者名字是否可用）
5. 进 Partner Center → Microsoft Edge → **新建扩展** → 上传 `dist/yanzhen-0.3.0.zip`
6. 填商品页（照 `store/listing.md` 复制粘贴）：
   - 名称、简短描述、详细描述
   - 分类：Productivity
   - 至少 1 张 **1280×800** 截图
   - **隐私政策 URL**
   - **权限说明**（⚠️ 必须填，见 `listing.md` 第四节）
7. 提交 → 等审核（几天）

---

## 第 3 步：上架 Chrome（要 $5）

流程和 Edge 几乎一样，差别：

1. 到 https://chrome.google.com/webstore/devconsole 用 Google 账号登录
2. **付一次性注册费**（我抓不到官方页面，你点进去看实际金额；印象里长期是 $5，**以页面为准**）
3. 上传同一个 zip
4. 除了商品页，Chrome 还会多问一份**「隐私实践」问卷**（你收集哪些数据、是否传给第三方）
   → 照 `store/listing.md` 第五节填
5. 提交 → 审核通常几天到两周

---

## ⚠️ 审核最可能被拒的三个原因 & 对策

| 被拒原因 | 为什么会发生 | 怎么改 |
|---|---|---|
| **权限说明不充分** | 你的扩展在所有网页运行（`<all_urls>`），审核想知道为什么 | 直接抄 `listing.md` 第四节的说明，重点那句"**只在用户按快捷键时读取选中文字，不读取页面 URL 和页面全文**"（这是事实，代码里确实没有） |
| **缺少隐私政策 / 隐私问卷不一致** | 你把用户文字发给第三方 API | 隐私政策 URL 填 `PRIVACY.md`；问卷里勾"传输给第三方"并说明是用户自己配置的 API |
| **zip 结构不对 / manifest 缺图标** | 多套了一层文件夹，或图标没引 | 用 `python store/pack.py` 打包，它自检不过就不出包 |

**被拒了不要慌**，改完重新提交，不额外收费。

## 上架之后：怎么发新版本

1. 改代码
2. **改 `manifest.json` 里的 `version`**（商店不允许重复版本号，必须更大）
3. 在 `CHANGELOG.md` 里记一条，并在商店后台填「更新说明」
4. `python store/pack.py` 重新出包
5. 后台上传新 zip → 提交审核

---

## 一句话提醒

**真正的门槛不是审核，是用户得自己搞两个 API key。**
上架只是把"装"这件事变简单了；"用"这件事还是很难。
如果以后要降低这一层，只有一条路：你自己提供 key（要服务器、要钱、要为结果背书）。
现在先别想这个，**先把包传上去。**
